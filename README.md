# How to run:

# 1. Extract this ZIP file.
# 2. Open index.html in a web browser.
# 3. Enter a 3-digit PIN, such as 258.
# 4. Click Start Brute Force.

# How it works:

# -> The computer starts from 000.
# -> It checks PINs one by one: 000, 001, 002, and so on.
# -> It stops when it finds the PIN entered by the user.
# -> The page shows the current guess, number of attempts, and progress.
